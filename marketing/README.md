# marketing/

**Histórico vivo de tudo que é marketing.** Versionado, organizado por tipo.

```
marketing/
├── conteudo/         # carrosséis, slides, posts, legendas
├── seo/              # saídas do pipeline /seo (8 passos numerados)
├── campanhas/        # CSVs do Google Ads + relatórios semanais
└── avaliacoes-google/ # respostas do GMB (opcional)
```

Cada skill que gera conteúdo determina o caminho exato. Você não cria pastas — a skill cria.

Exemplo:
- `/carrossel` → `marketing/conteudo/carrossel-<tema>-<YYYY-MM-DD>/`
- `/seo` → `marketing/seo/01-pesquisa-demanda.md`, `02-analise-concorrencia.md`, etc.
- `/relatorio-ads` → `marketing/campanhas/relatorios/semana-<AAAA-MM-DD>.md`
