# /syncar

Atalho para `/salvar`. Faz commit + push pro GitHub. Auto-configura o remote na primeira vez.

**Como executar:** Invoque a skill `.claude/skills/salvar/SKILL.md` (que tem o workflow completo com todos os casos: primeira vez, sem remote, com mudanças, sem mudanças, push com erro) e siga exatamente suas instruções. Este slash command é apenas um alias para evitar que o usuário precise digitar `/salvar`.

Gatilhos de uso: "salvar", "commit", "push", "subir pro github", "synca", "sincronizar", "fazer backup".
