# /iniciar

Atalho para `/abrir`. Carrega a memória persistente (`_memoria/` e `identidade/`) e devolve um resumo curto de 5 linhas do que importa agora.

**Como executar:** Invoque a skill `.claude/skills/abrir/SKILL.md` (que tem o workflow completo) e siga exatamente suas instruções. Este slash command é apenas um alias para evitar que o usuário precise digitar `/abrir`.

Gatilhos de uso: "iniciar", "começar", "vamos começar", "bom dia", primeira mensagem da sessão.
