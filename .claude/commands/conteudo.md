# /conteudo

Atalho/roteador. Encaminha para a skill correta baseado no que você quer produzir.

**Como executar:** Identifique qual das skills abaixo o usuário quer e invoque a SKILL.md correspondente:

| Você quer... | Invoque |
|---|---|
| Carrossel Instagram/TikTok (1080×1350 ou 1080×1920) | `.claude/skills/carrossel/SKILL.md` |
| Slide único (1080×1080, 1920×1080, 1080×1920) | `.claude/skills/slide/SKILL.md` |
| Roteiro de post/vídeo/thread/newsletter | `.claude/skills/roteiro-post/SKILL.md` |
| Pipeline completo (blog + carrossel + legendas) | `.claude/skills/publicar-tema/SKILL.md` |
| Publicar conteúdo já gerado | `.claude/skills/aprovar-post/SKILL.md` ou `.claude/skills/publicar-instagram/SKILL.md` |

Se o usuário não sabe qual, pergunte o que ele quer produzir (carrossel, slide, roteiro, conteúdo completo, publicar). Gatilhos: "conteúdo", "post", "material", "produzir conteúdo".
