# Design: Escolha

Este é o placeholder de estilo. Ao rodar `/carrossel`, você escolhe um dos 3 estilos:

1. **`design-minimalista.md`** — fundo limpo, tipografia forte
2. **`design-elaborado.md`** — editorial, gradientes, hierarquia complexa
3. **`design-tweet.md`** — simula print de Twitter/X

Cada um desses é um arquivo de regras de design nessa pasta.

## Como usar

Quando o usuário rodar `/carrossel`:

1. Pergunte qual estilo prefere (ou sugira baseado no tema)
2. Leia o arquivo `references/<estilo>.md` escolhido
3. Aplique as regras no HTML gerado

Não há regra fixa pra qual usar — depende do conteúdo:

- **Tema sério, técnico** → minimalista
- **Tema premium, storytelling** → elaborado
- **Tema polêmico, viralizar** → tweet
