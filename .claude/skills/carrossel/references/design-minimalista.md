# Design: Minimalista

Estilo limpo. Tipografia é o herói.

## Características

- Fundo uniforme (claro ou escuro, não os dois misturados)
- Tipografia bold/semibold, hierarquia clara
- Sem ícones ou ilustrações decorativas
- 1 cor de destaque por slide (geralmente a cor de acento da marca)
- Espaço em branco generoso

## Paleta típica (exemplo)

- Fundo: branco (#FFFFFF) ou preto suave (#0A0A0A)
- Texto principal: preto (#000) ou branco (#FFF)
- Acento: cor primária da marca (1 só)

## Tipografia

- Títulos: Inter Bold ou similar, 56-72px
- Subtítulo: Inter Medium, 28-36px
- Numerais de destaque: Inter Black, 96-120px (pra slides de dado)

## Layouts

### Layout 1: Citação centrada
```
        [espaço]
    
       CITACÃO CURTA
       em 3-5 linhas
    
        [espaço]
        autor / fonte
```

### Layout 2: Número + frase
```
       87%
    
       das empresas
       falham nisso
```

### Layout 3: Lista numerada (top 3)
```
       3 formas de
       dobrar conversão
    
   1. Melhor copy
   2. Mais tráfego
   3. Menos atrito
```

### Layout 4: Antes/depois
```
   ANTES              DEPOIS
    
   30 min/lead        5 min/lead
```

## Regras

- **Nunca** mais de 1 cor além do acento.
- **Nunca** textura ou gradiente.
- **Sempre** respire (espaço em branco).
- **Sempre** teste contraste mínimo AA.
- **Tipografia** consistente (mesma família, só varia peso e tamanho).
