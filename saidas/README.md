# saidas/

**Entregas pontuais.** Coisas que você fez uma vez e guarda por referência — não fazem parte do fluxo contínuo de marketing.

```
saidas/
├── analises/       # /analisar-dados
├── emails/         # /email-profissional
├── propostas/      # /proposta-comercial
├── slides/         # /slide (uso avulso, fora de conteúdo)
├── roteiros/       # /roteiro-post
├── estudos/        # análises exploratórias
└── outros/         # qualquer coisa que não encaixe
```

Diferença de `marketing/`: aqui fica o que **não** é conteúdo público sistemático. Email pra um cliente específico, análise interna, slide de apresentação interna. Lá em `marketing/` fica o que vira post, anúncio, página.
